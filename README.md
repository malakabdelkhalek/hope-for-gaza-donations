# 💚 Hope for Gaza — Donation Website

A front-end web project for a charity platform that collects donations for families in Gaza (food, medical help, shelter, education). Built as a university web development project at TEK-UP.

## Pages

| Page | Description |
|---|---|
| `index.html` | Home page: causes (food, medical, shelter, education) and call to action |
| `signup.html` / `login.html` | Account creation and sign-in forms with validation |
| `dashboard.html` | Donor space |
| `donation.html` | Donation flow with preset amounts (10, 20, 50 DT) |
